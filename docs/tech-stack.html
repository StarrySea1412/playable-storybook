01

呈现层RENDER

单个 index.html 承载全部版式与脚本：夜间主题、五章正文、手绘 SVG 图标、进度条与灯箱。零依赖、零构建，打开即读。

02

字体TYPEFACE

霞鹜文楷（OFL）按页面用字子集化：919 个字形压到两个字重各约 197KB；font-weight: 300 599 / 600 900 区间映射免做变量字体。

03

插画ARTWORK

七张水彩插图（AI 辅助生成，webp 合计约 1.0MB）+ 作品真实素材三枚：印章缩略图 11KB、封面 118KB，轻和统一可以同时要。

04

交互小样PLAYABLE

正文自带三枚可玩演示：帽子⇄蟒蛇印章切换（复用作品素材）、整页笔迹切换、活体星空 canvas（32ms 节流 · 离屏即停）。

05

图标系统ICONS

手绘 SVG 全套 15 枚：品牌印、五章章节图、三枚机关图、返工/事故图；上线前过三尺寸审计台（120/40/16px 并排目检）。

06

发布DEPLOY

GitHub Pages 静态直发（main 根目录 + .nojekyll），无 CI、无打包产物；改一处 push 即全网更新，打印/存 PDF 也有样式。
