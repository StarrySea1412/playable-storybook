- **五章制作手记**：重做而不是移植 / 让交互件穿上世界的衣服 / 一个 165KB 的笔迹 / 一片会呼吸的星空 / 写给每一种进入方式

## 关于这个仓库

单页文章站：`index.html` 单文件承载全部版式与脚本（零构建、零依赖、打印/存 PDF 友好）。排版使用**霞鹜文楷（LXGW WenKai）按本文用字子集化**的两个字重（OFL 许可，见 `assets/fonts/OFL.txt`，各约 197KB）；插图位于 `assets/`；技术栈全景图源文件在 `docs/tech-stack.html`（HTML → 无头浏览器截图 → PNG）。

本地预览（在仓库目录运行）：

```sh
python -m http.server 4321 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:4321/`。发布到 GitHub Pages 时直接部署仓库静态文件即可。
